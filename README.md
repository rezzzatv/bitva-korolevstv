# Битва королевств

Браузерная игра на HTML, CSS и JavaScript. Изображения встроены в `index.html`, установка зависимостей и сборка не требуются.

## Запуск

Откройте ссылку GitHub Pages или скачайте `index.html` и откройте его в браузере.

Текущая версия содержит игру против ботов. Публикация сайта сама по себе не добавляет сетевую игру между пользователями.

## Обновление

Замените `index.html` в ветке `main`. GitHub Pages автоматически опубликует новую версию, если настроена публикация из корня этой ветки.

## Отзывы тестировщиков

Сообщайте об ошибках во вкладке Issues: опишите шаги, ожидаемый и фактический результат, браузер и устройство. По возможности приложите скриншот.
